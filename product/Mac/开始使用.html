Mac 版使用说明

Apple 芯片（M 系列）· APFS U 盘 · 两个完整官方 App

U 盘里有什么

Hermes Agent通用 AI 助手
DeepSeek Harness编程用的 AI 工作台

两个程序都是完整官方版本，直接双击就能开，不需要先打开任何“工作站”或“配置中心”。

这是 Mac 专用盘。文件系统是 APFS，Windows 电脑不能读。 插到 Windows 上如果提示格式化，点“取消”，不要格式化。

第一次使用

  1. 双击 Hermes Agent 或 DeepSeek Harness。
  2. 如果 macOS 提示“无法验证开发者”，在程序图标上右键，选“打开”，再确认一次。
  3. 在程序自己的设置里填你自己的 API Key，或登录你自己的账号。
  4. 第一次启动会慢一点，是在从 U 盘读取程序本体；窗口没出来前不要反复双击。

使用边界

  • 本产品不附带 Key、不共享账号、不提供卖家代充或代理。
  • 模型服务由你自己选择、自己付费；使用过程需要联网。
  • 程序和聊天记录保存在当前这台 Mac 上，不写回 U 盘。换电脑要重新填 Key。
  • 程序开着时不要拔 U 盘；先退出程序，再在 Finder 里推出。
  • 不要删除、改名或单独搬走任何一个 .app；它们是完整程序包。
  • 这是 Apple 芯片版本，Intel Mac 不能运行。

出问题怎么办

先确认 Finder 里能看到 U 盘，根目录两个 .app 都在。程序打不开时，把整个 .app 从备份复制回来；不要拆开 .app 内部文件。

U 盘被误格式化后需要重新制作，请联系卖家获取同版本 APFS 母版。不要在 Windows 上格式化或“修复”这块盘。
