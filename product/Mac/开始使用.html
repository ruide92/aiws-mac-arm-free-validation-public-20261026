Mac 版使用说明

Apple 芯片（M 系列）· APFS U 盘 · 两个完整官方 App · 插盘双击

U 盘里有什么

Hermes Agent通用 AI 助手
DeepSeek Harness编程用的 AI 工作台

两个都是完整官方版本，直接双击打开，不需要先安装。U 盘不附带 API Key、账号或代理，Key 由你自己在 App 的配置中心里填写。

这是 Mac 专用盘。文件系统是 APFS，Windows 电脑不能读。 插到 Windows 上如果提示格式化，点“取消”，不要格式化。

第一次使用（按顺序做）

  1. 把 U 盘插到 Apple 芯片 Mac 上，在 Finder 里打开 AIWSMM0005。
  2. 双击 Hermes Agent 或 DeepSeek Harness。
  3. 如果 macOS 提示“无法验证开发者”，在程序图标上右键，选“打开”，再确认一次。官方签名版本通常不会出现这一步。
  4. 打开 App 后，进入它自己的配置中心（设置页），填入你自己的 API Key，选一个模型。
  5. 回到对话窗口，发一句话测试；能正常回复就配置好了。第一次启动会慢一点，窗口没出来前不要反复双击。

配置中心怎么填

两个 App 各自带配置中心，不需要先打开任何“工作站”。第一次打开时按界面提示走；找不到入口时，照下面找：

Hermes Agent

  1. 打开 App，点左下角或右上角的 设置 / Settings。
  2. 找到 模型服务 / Providers / API Keys。
  3. 选你用的服务商（OpenAI、DeepSeek、Anthropic、OpenRouter 等），粘贴对应的 API Key；如果你用的是兼容 OpenAI 的中转服务，按它的说明填 Base URL 和模型名。
  4. 保存后，在模型选择器里选中刚配置的模型。

DeepSeek Harness

  1. 打开 App，点左下角 设置 / Settings。
  2. 进入 模型 / Models，找到 DeepSeek 卡片（或“添加自定义提供方”）。
  3. 粘贴你自己的 API Key；用第三方兼容服务时，同时填它的 Base URL 和模型 ID。
  4. 保存后回到会话，在模型选择器里选中该模型。
只填自己的 Key。Key 只保存在你当前这台 Mac 上（App 自己的配置/钥匙串），不会写回 U 盘，也不会发给卖家。换一台电脑要重新填。

使用边界

  • 本产品不附带 Key、不共享账号、不提供卖家代充或代理。
  • 模型服务由你自己选择、自己付费；使用过程需要联网。
  • 程序和聊天记录保存在当前这台 Mac 上，不写回 U 盘。
  • 程序开着时不要拔 U 盘；先退出程序，再在 Finder 里推出。
  • 不要删除、改名或单独搬走任何一个 .app；它们是完整程序包。
  • 这是 Apple 芯片版本，Intel Mac 不能运行。

出问题怎么办

先确认 Finder 里能看到 U 盘，根目录两个 .app 都在。程序打不开时，把整个 .app 从备份复制回来；不要拆开 .app 内部文件。

U 盘被误格式化后需要重新制作，请联系卖家获取同版本 APFS 母版。不要在 Windows 上格式化或“修复”这块盘。
