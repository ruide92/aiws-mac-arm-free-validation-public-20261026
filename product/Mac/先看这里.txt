========================================
  先看这里（Mac / Apple 芯片）
========================================

这个 U 盘是 Mac 专用盘，文件系统是 APFS。
Windows 电脑不能读它，插到 Windows 上如果提示格式化，点“取消”，不要格式化。

根目录只有两个程序，都是完整官方版本，不需要安装：

    Hermes Agent        通用 AI 助手
    DeepSeek Harness    编程用的 AI 工作台

两个都可以单独双击打开，不需要先开任何“工作站”或“配置中心”。

----------------------------------------
第一次用
----------------------------------------

1. 双击 Hermes Agent 或 DeepSeek Harness。
2. 如果 macOS 提示“无法验证开发者”，在程序图标上右键，选“打开”，再确认一次。
3. 在程序自己的设置里填你自己的 API Key，或登录你自己的账号。
4. 第一次启动会慢一点，是在从 U 盘读取程序本体；窗口没出来前不要反复双击。

本产品不附带 Key、不共享账号、不提供卖家代充或代理。
模型服务由你自己选择、自己付费；需要联网。

----------------------------------------
要记住的几条
----------------------------------------

- 程序和聊天记录保存在你当前这台 Mac 上，不写回 U 盘。
  换一台电脑，程序照样能开，但要在新电脑上重新填 Key。
- 程序开着的时候不要拔 U 盘。先退出程序，再在 Finder 里推出 U 盘。
- 不要删除、改名或单独搬走任何一个 .app。它们是完整程序包。
- 不要在 Windows 上格式化这块盘，也不要用 Windows 的“优化/修复”工具处理它。
- 这是 Apple 芯片（M 系列）版本，Intel Mac 不能运行。

----------------------------------------
出问题怎么办
----------------------------------------

先确认 U 盘在 Finder 里能看到，并且根目录两个 .app 都在。
如果程序打不开，把整个 .app 重新从备份复制回来即可；不要拆开 .app 内部文件。
如果 U 盘被误格式化，需要重新制作，请联系卖家获取同版本 APFS 母版。
